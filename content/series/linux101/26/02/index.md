## 从图灵到 Transformer：我们在谈论怎样的 AI？

从图灵测试、感知机、CNN 到 Transformer，再到 AGI，我们会沿着这些概念，聊聊“AI”在日常语境中的含义发生了怎样的变化。

Diffusion 和 **Next Token Prediction** 有什么区别？什么是生成式模型、什么是 AIGC？为什么一个看似只是“接下一个词”的接话游戏，竟能展现出复杂的能力？这些问题都会在这一讲里展开。

当然，也少不了一起欣赏一些 AIGC——看看能不能让你再次**“眩晕瘫坐，像看到原子弹爆炸”**。

## 模型为什么这么烧钱？

我们会认识形形色色的 **Scaling Law**，看看模型训练和推理分别在做什么：为什么训练一个模型很烧钱，为什么训练完了、让用户使用它，依然很烧钱？

还有离钱包最近的几个词：**API Key、Token 和账单**。调用模型时，究竟在为什么付费？从使用到保管 API Key，有哪些事情不能稀里糊涂地交给模型？

## 从 Chat 到 Agent：不只是换了个聊天窗口

什么是 **Agent**，什么又是 **Harness**？当模型从回答问题，变成能够调用工具、操作环境、执行任务的系统，为什么会让人感到智能程度发生了全面飞跃？

这一讲会把模型和围绕模型运行的工具、环境与执行流程放在一起看，理解从“告诉你怎么做”到“帮你动手做”之间，究竟多了什么。

## AI 时代的开源社区，以及 Agent 的原生家庭

开源模型、开放权重模型和闭源模型有什么区别？从开源训练与推理框架，到开源、闭源的 Agent，我们会看看 AI 时代的社区正在做什么。

也会聊聊那些热闹背后的问题：GitHub 为什么动不动就崩溃，为什么总有看不完的 CVE 和安全事故？这些现象背后有哪些值得警惕的风险？

最后回到 Linux 101：**Linux 和开源工具，为什么会成为 Agent 的原生家庭？** 当模型开始使用终端、读写文件和调用工具，第一讲里认识的那些东西，就不再只是我们自己使用的工具了。

## 人类如何与 Agent 协作？

Agent 能闯哪些祸？有哪些事情仍然做不了，或者做得很差？我们该怎样交代任务、检查结果、纠正它的奇怪行为，而不是把判断也一并外包？

这一部分，我们一起探索和 Agent 共事的方法，**共同维护人类最后的尊严**。
