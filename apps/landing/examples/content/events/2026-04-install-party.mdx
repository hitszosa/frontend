## 活动简介

Install Party 是面向 Linux 新用户的现场交流与安装活动。参与者可以带上自己的电脑，在志愿者协助下了解发行版、准备安装介质，并解决双系统和磁盘分区中的常见问题。

## 现场内容

- 根据使用需求选择合适的 Linux 发行版；
- 制作并检查启动安装介质；
- 了解 UEFI、启动顺序和磁盘分区；
- 讨论 Windows 与 Linux 双系统方案；
- 处理驱动、网络和安装后的基础配置问题。

## 参加前准备

如果计划现场安装系统，请提前备份重要文件，并为设备保留充足电量。涉及磁盘分区的操作存在数据风险，现场协助不能替代个人备份。

不准备立即安装也可以参加：你可以先了解完整流程、体验不同桌面环境，或带着已有系统的问题来交流。
