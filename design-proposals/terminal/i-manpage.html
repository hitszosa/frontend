HITSZ User Commands OSA(1) 26 July 2026

NAME

osa —

HITSZ 开源技术协会

SYNOPSIS

  • osa[ --home=首页 --events=活动 --links=友链 --about=关于 --mirror=镜像站 --wiki=Wiki ]
  • osaopen{ 访问镜像站 | 社团活动 | 了解协会 }

DESCRIPTION

我们是 HITSZ 开源技术协会（a.k.a. HITSZ OSA），由哈尔滨工业大学（深圳）学生中的 Linux 用户和开源软件爱好者自发组建的学生社团。我们致力于维护学校的开源基础建设，提升学校开源氛围，为开源技术爱好者提供交流平台。

不论你正在编译内核、寻找稳定的软件源，还是第一次听说自由软件，osa 都欢迎你。

SERVICES

-m, --mirror
开源软件镜像站online
主流 Linux 发行版与开源软件的高速校园镜像。
-h, --mirror-help
镜像使用帮助online
查阅换源说明与常见软件源配置。
-w, --wiki
OSA Wikionline
Linux 入门、HPC 文档与协会知识库。
-n, --weekly
Weekly 周报online
每周开源资讯与社区近况。
-g, --gitea
Gitea 代码托管online · 校内
面向校内成员的轻量代码协作服务。
-a, --ai-gateway
AI Gatewaybeta · 校内
统一接入主流大模型 API。
