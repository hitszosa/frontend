## 活动简介

参与上游社区并不始于一次庞大的代码提交。报告问题、补充文档、复现错误，以及参与讨论，都可以成为第一次有效贡献。

本次分享围绕一条真实、可重复的参与路径展开：从找到合适的项目与任务，到提交第一个 issue，再到准备并合并第一个 PR。

> 具体时间、地点与参与方式确认后将在本页持续更新。

## 本次分享将覆盖

- 如何阅读项目的贡献指南与社区规则；
- 如何找到适合初次参与的 issue；
- 提交问题时需要准备哪些复现信息；
- 从 fork、分支、commit 到 pull request 的基本流程；
- 如何回应 review，并与维护者保持有效沟通。

## 适合谁

- 想参与开源、但不知道从哪里开始的同学；
- 已经使用 GitHub，希望理解协作流程的开发者；
- 维护个人项目，希望改善贡献体验的同学。

## 参加前可以准备

建议提前准备一个 GitHub 账号，并熟悉基础的 Git 操作。没有贡献经历也没有关系，活动会从完整流程开始讨论。
